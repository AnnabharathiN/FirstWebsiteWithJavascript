# First Website With JavaScript

My first interactive website combining HTML and JavaScript,
completed as part of the Full Stack MERN Developer Bootcamp
at Matrix Master, Rotterdam.

## Features

- Interactive web form with JavaScript validation
- Form submission handling
- Dynamic page updates using JavaScript
- Multi-page navigation — main page and submission page

## Technologies Used

- HTML5 — page structure and forms
- JavaScript (ES6+) — form validation and interactivity

## What I learned

- Connecting JavaScript to HTML pages
- Handling form input and validation
- DOM manipulation — reading and updating page content
- Creating multi-page websites
- Writing and linking external JavaScript files

## How to run

1. Clone the repository
2. Open WebsiteAssignment.html in your browser
3. Fill in the form and submit to see JavaScript in action!
